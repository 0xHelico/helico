# @helico/landing

Public landing page. Astro 7 starter from the official `minimal` template, TypeScript
strict, placeholder copy. Plan: [`docs/plans/2026-09-05-landing-starter.md`](../../docs/plans/2026-09-05-landing-starter.md).

## Run

```bash
bun run --filter @helico/landing dev        # http://localhost:4321
bun run --filter @helico/landing typecheck  # astro check, covers .astro and .ts
bun run --filter @helico/landing build      # static site in dist/
```

## Layout

- `src/layouts/Base.astro`: html shell with typed `Props` (`title`, `description`)
- `src/pages/index.astro`: the only page, placeholder content
- `AGENTS.md`: Astro's instructions for coding agents, generated by `create-astro`; `CLAUDE.md` imports it

## Not here yet

Real copy, a styling framework (`bun astro add tailwind` when a design exists), SEO,
analytics, hosting. Biome does not touch `.astro` files; `astro check` does.
